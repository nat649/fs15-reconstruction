# Project direction

- This is a decompilation and reconstruction of Farming Simulator 15 / GIANTS Engine 6.
- Prioritize recovered scripts, original resources, native analysis and reuse of existing engine components where practical. Keep this direction when extending the project.
- Preserve original map geometry, transforms, scale and materials; identify temporary rendering approximations explicitly.
- Distinguish original native components, reconstructed behavior, third-party decoders and authored host code. Do not describe the full GIANTS engine as rebuilt before it is validated.
- Keep original executables, code snapshots, recovered game sources, mesh caches, textures and local packages out of Git. Requested rendered screenshots may be published.
- Keep GitHub documentation and the checkbox checklist in English. Explain progress to the user in French.
- See `docs/RECONSTRUCTION_STRATEGY.md`, `docs/ENGINE_BOOTSTRAP.md` and `PROJECT_CHECKLIST.md` for current scope and evidence.
